# Mini Compiler Stages Simulator (COAL Project)

## Description
This project is a C# Windows Forms application that simulates the basic phases of a compiler including Lexical Analysis, Syntax Analysis, and Intermediate Code Generation.

## Features
- Lexical analysis (token generation)
- Symbol table generation
- Syntax analysis with parse tree
- Intermediate code generation (ICG)
- Interactive GUI interface

## Compiler Phases Covered
1. Lexical Analysis
2. Syntax Analysis
3. Intermediate Code Generation

## Technologies Used
- C#
- Windows Forms (WinForms)
- Object-Oriented Programming

## Output Includes
- Token Table
- Symbol Table
- Parse Tree
- Intermediate Code

## Purpose
To understand and visualize the working of compiler phases in a simplified educational manner.
